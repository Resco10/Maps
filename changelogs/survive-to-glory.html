Update 1.3.2 — Patch Update

24 April 2022

New Features

  • Vanilla Tweaks Data Pack added.
  • Vanilla Tweaks Crafting Data Pack added.

Fixes

  • Updated map to 1.18.2.
  • Updated Vanilla Tweaks Resource Pack to 1.18.2.
  • Updated TreeCapitator to 1.18.2.

Datapack / Resource Pack Log

  • 3D Amethyst Crystals, Glow Lichen, Doors, Trapdoors and Bookshelves.
  • Removed Java Edition title from GUI.
  • Scoreboards: Track Raw Statistics and Track Statistics.
  • Teleportation: Spawn and Homes.
  • Crafting QoL: Rotten Flesh to Leather, More Bark, More Stairs and More Bricks.
  • Datapacks are pre-installed; resource packs are included in the ZIP and need to be placed in the resource pack folder.

Update 1.2 — Quality of Life Update

20 July 2021

New Features

  • Shulker Box Swapper.
  • Armor Stand Case.
  • All workplaces added.
  • Enchanting Table area.
  • Beacon.
  • Two new animal pens: pigs and chickens.
  • Automatic cactus, sugar cane and melon/pumpkin farms.
  • Semi-automatic wheat/beetroot/carrot/potato farm.
  • Easter egg teasing the next update.

Changes

  • Revamped underground area, main floor and animal pens.
  • Removed all non-automatic farms.
  • Removed a large amount of trees and all dirt paths.

Fixes

  • World spawn moved to the base.
  • Compatibility with 1.17.1.

Resource Pack

  • Added 3D Chains, Pointed Dripstone, Items, Lily Pads and Vines.
  • Replaced borderless glass variants with clean glass variants.
  • Added Smoother Font.
